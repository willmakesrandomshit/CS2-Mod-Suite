# Contributing

Bug reports and focused pull requests are welcome.

For a bug, include the mod and version, CS2 version, exact steps, expected and
actual result, relevant other mods, and a screenshot/video or inspected log
when useful. Reproduce in a disposable city when the report involves traffic,
save recovery, access routing or other experimental simulation behaviour.

For code changes:

1. Keep the change inside the mod's stated scope.
2. Follow native CS2 interaction patterns and existing UI terminology.
3. Do not add controls that are disconnected from runtime behaviour.
4. Do not manufacture precision, causes, performance gains or test results.
5. Build the affected C# and UI projects before submitting.
6. State exactly what you tested and what remains unverified.
7. Do not commit game assemblies, generated output, saves, logs or secrets.

Large unrelated feature bundles are harder to review and may be asked to split.
Contributions to GPL-licensed projects must remain compatible with GPL-3.0.
