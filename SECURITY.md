# Security policy

Do not open a public issue containing credentials, private logs, crash dumps,
personal save data or private filesystem information.

For a security-sensitive problem, use GitHub's private vulnerability reporting
for this repository if it is available. Include the affected mod/version,
impact, reproduction details and the smallest necessary redacted evidence.

Ordinary crashes, compatibility problems and gameplay bugs belong in a normal
bug report after personal paths and private data have been removed. Exported
CrashLens reports should always be inspected before sharing.

No recovery, diagnostic or save-management mod can guarantee that a damaged
save is recoverable. Keep independent backups of important cities.
