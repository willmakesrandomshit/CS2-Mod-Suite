# Road Rules — Lane & Vehicle Restrictions

Edits supported native access, soft preferences and closures for physical lanes
on a selected carriageway.

- **Source status:** 1.4.5-beta.1; class/overlay runtime matrix partially verified
- **PDX:** [mod 155436](https://mods.paradoxplaza.com/mods/155436/Windows)
- **Licence:** MIT
- **Build:** follow [BUILDING.md](../BUILDING.md); C# is in the project root and React UI source is in `UI/src`
- **Important limits:** Public/Service Lane is not bus-only; No Heavy Traffic and Local Bias are soft preferences; existing routes may take time to clear
- **Issues:** report the road prefab, carriageway/lane shown, rule, overlay, newly routed traffic and Advanced Debug routing members
