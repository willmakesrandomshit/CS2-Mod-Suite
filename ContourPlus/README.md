# Contour Plus

Terrain contour overlays and terrain/road-grade planning readouts with
configurable intervals and visibility.

- **Source status:** 1.2.5-beta.1
- **PDX:** [mod 155427](https://mods.paradoxplaza.com/mods/155427/Windows)
- **Licence:** MIT
- **Build:** follow [BUILDING.md](../BUILDING.md); C# is in the project root and React UI source is in `UI/src`
- **Important limits:** contours are off by default; effective intervals can increase to bound work; measurements are planning aids, not surveying data
- **Issues:** report map, interval/profile settings, camera/terrain location, expected line and a screenshot
