# CrashLens

Collects available local error evidence and exports a support report. Suspect
ranking is evidence triage, not proof that a mod caused an error.

- **Source status:** 1.1.4-beta.1
- **PDX:** [mod 155239](https://mods.paradoxplaza.com/mods/155239/Windows)
- **Licence:** MIT
- **Build:** follow [BUILDING.md](../BUILDING.md); C# is in the project root and React UI source is in `UI/src`
- **Important limits:** no evidence does not prove health; reports remain local and may contain private context beyond redacted profile paths
- **Issues:** inspect and redact every report before sharing it
