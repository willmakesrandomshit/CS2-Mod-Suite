## BuildGuard feasibility (evidence)

- Game assemblies (1.6.4f1) show the vanilla tools build `Game.Tools.Temp` preview entities with
  `TempFlags` {Create, Delete, Replace, Upgrade, Modify, ...}, `m_Original` and `m_Cost`. A read-only
  summary of "what the preview will delete or change" is therefore technically plausible without
  patching the game. Branch `feat/buildguard-prototype` implements exactly that and builds.
- Differentiation is **not** established: the web search could not find a mod with a dedicated
  pre-commit impact summary, but it also could not retrieve competitor feature lists or subscriber
  counts, so "nobody does this" is unproven. Check Move It, Anarchy, Road Builder, Network Tools and
  Easy Zoning pages directly before treating this as the flagship.
- Release 2 (restoring other mods' data after an edit) is untouched and unproven.
