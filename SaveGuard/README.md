# SaveGuard

Inspects local save packages and creates restore points or separate restored
copies. Restore As Copy does not overwrite its source.

- **Source status:** 1.2.4-beta.1
- **PDX:** [mod 155424](https://mods.paradoxplaza.com/mods/155424/Windows)
- **Licence:** MIT
- **Build:** follow [BUILDING.md](../BUILDING.md); C# is in the project root and React UI source is in `UI/src`
- **Important limits:** archive readability is not proof that CS2 can load a save; recovery is never guaranteed; keep independent backups
- **Issues:** reproduce only with disposable copies and never attach private saves publicly
